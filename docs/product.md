# TripTalk 交互规则与 Jane 角色设定

文档基线 v0.9 · 2026-11-12。本文定义产品行为，不定义工程优先级；实施范围以 [开发节奏](development-plan.md) 为准。教学契约见 [Jane Agent 设计](agent-design.md)。

状态标记：**已确定**来自用户明确要求；**建议默认**是可以用于首版原型的方案，不等同于用户已最终确认；**待补充**需要后续选择。本文为目标规范，不代表功能已实现；阶段状态见开发节奏。

## 1. 已确定的产品方向

- 产品是网页版英语学习应用，以旅行词汇与场景对话为主要内容。
- 整体可爱、清新，采用奶蓝主色、奶白背景、深蓝文字；以少量浅桃、淡黄、淡紫点缀反馈。
- Jane 是贯穿学习过程的动画女孩助教，每次开始课程前出现，并负责欢迎、引导、讲解、反馈和结束串联。
- Jane 外观固定为黑棕色头发、马尾辫、齐刘海、黑框眼镜。
- 首次进入默认显示场景学习模块；必须提供错题本。
- 有未完成场景时显示“继续 XX”；上一场景完成后提供“新场景”和“复习”。
- Jane 的台词、动作和表情可结合天气、心情、来访频率变化，包含开心、幽默、忧郁、轻微生气等表现。
- 对话与复习等业务记录保存到项目本地文件，由本地 Node 服务管理；这是最新确定要求，覆盖旧稿浏览器保存建议。

## 2. 完整文字 MVP 的范围与导航（P3 目标）

**已确定（2026-11-09）：**顶部导航精简为“场景学习 / 复习与错题”；复习页内部使用“错题本 / 收藏表达”切换，不额外增加表达本一级入口。具体布局见 [设计索引](../design/README.md)。设置与学习记录的入口后续再细化，不在当前视觉稿加入常驻菜单；声音、天气相关设置随 P4 能力开放。首页直接展示内容，不强制注册或填写长问卷。

| 模块 | 首版内容 | 状态 |
| --- | --- | --- |
| 场景学习 | 酒店、机场、餐厅、交通固定；首次开始生成 3–8 个有边界、低重复主题，依次学习 | 已确定并接通，生成质量待人工试聊 |
| 错题本 | 原回答、问题、纠正表达、解释、重试与复习入口 | 模块已确定；详细规则建议默认 |
| 随身表达本 | 主动收藏词汇和整句，保留来源场景 | 建议默认 |
| Jane 助教 | 欢迎、课程引导、提示、纠错、完成反馈 | 已确定 |
| 学习记录 | 各场景进度、完成记录、待复习内容 | 建议默认 |

P1 已从酒店入住扩展为固定场景下的动态主题文字练习；P1.5 SQLite 已验收，P1.6 录音输入与句子点播已接入待真实验收。后续为 P2 独立自由聊天、P3 完整课程/复习；实时语音、统一云端音色、发音评分、天气和精细动画留在 P4 按需评估。四个场景共用生成流程；未实现能力的演示反馈必须标为示例。

P1 最小练习页包含静态 Jane、当前任务、角色对话、独立教学反馈、文字输入、提示/解释入口、发送中与失败状态。Agent 先生成主题对话计划与情境；程序在回答通过后自动提交已校验的下一问，不要求逐题点击继续，不允许无限生成计划外问题。只完成这段练习时显示“本段练习完成”，不冒充已完成整课。

## 3. 首页的三种来访状态

**建议默认判断顺序：**存在未完成会话 → 优先续学；否则有完成记录 → 展示后续选择；否则尚未完成引导 → 首次欢迎；其余 → 简短欢迎与场景列表。引导结束与是否选课独立保存。

P1 完成记录代表该主题完成；回到场景优先下一未完成主题，全部主题完成才显示“本场景主题已练完”。这不等于 P3 含词汇/示范/复习的完整课程认证，不显示虚假复习入口。

| 状态 | Jane 的表现与示例台词 | 主要操作 | 辅助操作 |
| --- | --- | --- | --- |
| 首次来访 | 静态挥手：“Hello，我是 Jane！很高兴认识你，让我们一起开始旅行英语学习吧。” | 选择难度，点击“开始场景”；目录生成前进度留白 | 可换场景，不强制等待问候 |
| 有未完成课程 | 指向续学卡：“Welcome back！我们上次练到酒店入住的早餐问询，接着来吧。” | “继续酒店入住” | 回看上一句、换场景 |
| 上一课程已完成 | 微笑、轻握拳庆祝：“Nice work！想去下一站，还是再巩固一下？” | “新场景” | “复习错题”与“重练整个场景” |

- 续学卡显示场景名、阶段和具体轮次，不仅显示百分比。
- 首次首页与续学首页共用布局。目录未生成或生成中只保留空白进度占位；成功后显示 0 / 实际主题数和“立即学习”，自动打开课程安排，不写死 4。失败可重试，不预填虚假目录。
- 主卡展示当前选择场景的最近未完成主题；各场景进度独立，切换不清空。当前默认进入酒店，可通过场景卡切换。
- 换场景或选择新场景不会清空旧课程进度；重练会新建一次练习记录，保留历史完成记录。
- 没有错题时不显示虚假的待复习数量；提供“重练整个场景”或“复习收藏”。
- 已完成所有可用课程时，主入口切换为复习，不推荐不存在的新课。
- 天气、进度、错题数必须来自真实状态；交互稿上的示例数字不应硬编码进正式产品。

## 4. 场景、主题与学习流程

**已确定（2026-11-12）：**场景人工配置，主题由独立场景规划 Agent 首次生成 3–8 个。覆盖常用沟通任务，主题粒度相近且核心目标不过度重复，每个主题说明范围和边界。酒店入住、退房、餐饮、设施只是主题示例，不是必须输出的固定清单。每主题正常进行一次对话，完成后学习下一主题；只有明确选择重练才再生成。

每主题开始时 Agent 生成 8–15 个训练问题的模拟对话计划与虚构情境，程序校验保存。一个训练问答是 Jane 提问和用户有效回应；求助、解释、重答不计新问题。计划不是逐字剧本，允许根据真实回答改变问法，提前覆盖信息不重复问。8–15 是计划长度而非强制消息条数，不为凑数追问；上限与完成规则见 Agent 设计。

固定配置定义场景及范围、安全要求和数量边界；主题目录生成后保存、恢复复用。人数、日期、服务时间等由主题规划 Agent 生成，不放固定配置；同一次练习保持一致，中文任务中的身份明确为虚构。

**已确定：**三档难度：简单（小学/初中）、中等（默认，高中/大学）、高级（面向雅思/托福学习者）。提高难度时词汇和语法更丰富，但不按考试打分、不把正确简单表达判错。首页选择保存为新主题偏好，现有对话沿用开始时难度；不重新生成主题目录。预计时长待实际试练，不承诺固定分钟数。

### 4.1 进入课程

首次“开始场景”生成目录，保存成功后自动打开课程安排；用户点击“立即学习”才生成首个主题的具体对话，保存后进入课程。两次调用分别保存，不绑定成易重复计费的大请求。Jane 简短说明任务，恢复不重复自我介绍或生成。后续按目录进入下一未完成主题。

**已确定（2026-11-17）：课程安排弹窗**

- 仅本次初始化成功自动打开；关闭、刷新或返回首页不重复弹出。目录生成后，场景名称右侧的 ⓘ 可随时重开；打开/关闭不请求模型、不保存额外偏好。
- 目录只查看顺序、目标摘要和真实状态，不点击主题跳课。首页保留直接学习入口，与弹窗共用同一操作。
- 未开始显示「立即学习」；有未完成会话显示「继续学习」并恢复原会话；部分完成且无进行中的会话显示「学习下一主题」；全部完成显示「再练一次」，明确新建首主题的练习，保留历史。
- 存在未确认的创建请求时，「重试原操作」优先于以上文案，并复用原 requestId、主题、难度。弹窗难度也优先显示该请求/续学会话的实际难度，其他情况显示新主题偏好。
- 创建对话时显示准备状态、防重复提交；失败保留弹窗，显示同步/重试入口，不重新生成整个场景目录。生成目录失败则留在首页，不弹出空课程。
- 弹窗只保存在当前页面状态，不进入 profile.json 或场景文件。布局细节见 [设计索引](../design/README.md)。

### 4.2 关键词

- 每课建议 3–5 个关键词或短语，展示英文、词义、场景例句。
- 支持“显示释义 / 收藏 / 下一个”。首版可以先展示英文，再由用户展开中文。
- 同一词汇在后续对话中再次出现；收藏不影响课程完成条件。
- 有音频时提供发音按钮；没有音频时不显示可点击的假播放控件。

### 4.3 示范对话

- 明确区分旅客、前台等场景角色，以及负责教学的 Jane。
- 中文辅助可开关；有音频时支持逐句播放和重播。
- Jane 点出本课一个关键句式，用户可回看，不强制观看固定时长。

### 4.4 角色练习

- Jane 为引导提问方，每轮显示一个英文问题和中文作答任务，例如“我要入住”“两位大人一个小孩”，用户输入英文回应。任务不是默认英文答案。
- 点击 Jane 的训练问题显示该句中文释义，10 秒后自动消失；点击中文气泡或再次点击英文可立即关闭，同时取消并清空定时器。重新打开从新的 10 秒开始，旧定时器不会关闭新气泡；点击外部或 Esc 也可关闭。顶部当前问题与历史提问均支持，键盘聚焦后 Enter/空格可切换，中文气泡也可用键盘关闭；拖选文字时不触发关闭。不因悬停触发，只读取已保存翻译，不请求模型、不计求助、不改进度；旧问题无翻译时保留普通文字，不伪造释义。角色回应、结束语和用户回答不在本次范围。
- P1 优先文字输入，以验证真实多轮对话；选择题不是前置依赖。P1.6 增加录音转文字，始终保留文字入口，见第 4.8 节。
- 参考回答默认隐藏，只在点击“给点提示”后提供关键词、句式或完整参考。P1 补充按需展开的参考回答辅助：点击填入输入框，可编辑后发送；不直接提交，不作为多选题，不自动通过。有草稿时确认替换。布局和键盘行为统一见设计索引。
- 按钮求助（action=hint）只在输入框上方展示当前题最新的 hint.text，不在主对话列表显示“给点提示”、角色回应或教学说明；已保存的历史求助也遵循此展示规则。后台记录和三级提示次数保留，刷新恢复当前题提示，切换题目后不沿用上一题提示；文字作答和词句解释的展示不变。
- 自然语言请求提示、问词义、要求解释时先帮助，保持当前任务，不判错、不推进；回应规则与输出契约见 Agent 设计。
- 评价首先判断是否表达了本轮意图；语义正确的其他说法不能仅因与标准答案不同而判错。
- 反馈分为“表达正确”“意思正确但可更自然”“关键含义有误”“无法判断 / 没听清”。
- 前两类自动接着提问；自然度建议不会自动算错题，用户可收藏改进表达。纠正与解释保留在原回答下方，下一问追加为新消息，输入区同步切换中文任务。
- 明确语法或语义错误给出纠正与解释并记入错题；轻微语法错误但可理解时允许继续，含义错误或影响理解时重试。自然度建议不等于错误，语境正确的短句与正确变体不记错。
- 识别失败、超时或未输入不算语言错误，不加入错题本。
- P1–P3 暂不提供跳题，只提供求助、重试和暂停，避免加入未定义的回补流程；暂停不标完成。跳题能力待后续需求确认。

### 4.5 主题完成与结束后选择

主题完成以本次计划中的问题已解决（含有证据的提前覆盖）、最后反馈和结束语成功保存为准，不按发送消息数判断，不再额外点击“完成本主题”。Jane 根据实际表现给一句鼓励或幽默结尾，不虚构全对。

P1 结束语后显示“选择下一步”，返回所属场景查看进度、调整难度并开始下一主题；不自动跳转或重新练上一主题。“和 Jane 自由聊聊”明确未开放。P2 开放独立聊天；后续可把下一主题名称直接展示在完成卡上。

### 4.5.1 完整课程条件

**建议默认：**已浏览关键词、已查看示范对话、该课程要求的主题均完成且各主题最后反馈与结束语已保存，即本次课程完成并进入小结。允许借助提示完成，并记录是否使用提示。真实模式评估失败时保留原任务并允许重试；不降级为自评过关。若后续实现演示模式，演示数据与真实进度隔离。

结束页展示：已完成场景、实际待复习数量、一句可收藏的实用表达、“新场景 / 复习错题 / 重练整课”。不展示未经测量的口语分数。“课程完成”不自动将错题或全部词汇标为掌握。

### 4.6 酒店课程内容

关键词可从本次计划提取并人工抽查。原固定三题方案退役；目录与生成计划边界见 [Agent 设计](agent-design.md)。新场景生成 3–8 主题，并按目录顺序学习。目录需抽查覆盖面与重复度，对话需检查范围、难度、长度和事实一致性。

### 4.7 自由聊天

仅由用户在主题结束后主动进入；Jane 恢复助教/朋友身份。自由聊天与训练使用不同会话 ID，关联来源训练会话但分别记录，不改变课程进度、不自动生成错题。可主动收藏；聊天历史默认不混入后续训练。界面标注“自由聊天”，隐藏训练计数与中文作答任务，提供返回场景/继续可用任务入口。

### 4.8 录音输入与句子播放（P1.6）

**已接入：**“录音 → 转文字 → 编辑确认 → 发送”，以及用户点击 Jane 英文句子旁的图标播放。真实设备与模型质量仍待用户验收；不做实时通话、自动播报或发音评分。

- 用户主动点击麦克风开始，支持结束和取消；录音/识别状态明确，不能与回答提交同时进行。停止、取消或离开页面时释放麦克风。
- 结束录音后识别，结果追加到最新可编辑草稿，用户确认后按原发送规则提交；不自动发送、不自动推进。识别期间仍可编辑文字；合并超过 2,000 字时保留完整转写预览，允许精简草稿后追加或自行复制，不截断、不覆盖。取消、换题、切后台或离页后忽略迟到结果并释放资源。
- 转写尽量忠实保留原词和语法，不先润色再给 Jane 评价。识别仍可能纠正或误听，需验证学习者口音及错误表达；用户可修正，不能据转写文本声称完成发音评分。
- 拒绝权限、无设备、浏览器不支持、未识别出语音或网络失败时给出具体提示并保留文字入口；这些不是学习错误，不计错、不改变进度。
- 原始录音不默认落盘；只有确认发送后的文本按正常学习记录保存。首次使用说明音频将发送至云端识别，不把“本地保存学习记录”描述成“音频不出本机”。
- 每段最长 60 秒、5 MB，过短/明显静音在浏览器提示；服务端限制请求体和耗时，只允许单个转写在途，不自动重试。默认 gpt-transcribe，独立配置及网络边界见 OpenAI 接入；尚无按月总额封顶功能。
- Jane 问题与角色回应的消息下方显示小型播放图标，再点停止，点另一句切换。以较慢的 0.9 倍速优先使用系统本地英语音色，缺失时由浏览器选择；声音受设备/系统影响，部分语音可能需要网络，不承诺完全离线或统一 Jane 音色。整句播放，不额外实现选词朗读。
- 播放不请求教学模型、不写数据库；录音开始、切后台、换题或离页会停止。识别期间也禁用播放；播放错误就近提示，原有选词与翻译行为不变。

## 5. 进度保存与恢复

以下均为**建议默认**，从 P1 正式对话原型开始实现；P1 验收包含 JSON 保存与续学，不以 CLI 内存调试为前置。

- 每次提交回答时将反馈与自动推进结果一起保存，不只依赖用户点击退出；只有成功保存才显示下一问。
- 不理解、偏题或不符合当前任务的孤立数字显示 Jane 的普通中文引导，不推进、不计错；数字用于人数、房间号等任务时允许合理作答。系统故障与教学反馈分开呈现，完整异常分类见 [数据契约](data-contracts.md#异常分类与诊断)。
- Enter/发送后立即显示一条本地用户气泡及等待状态，同时清空输入框、退出本次解释模式；完整请求与清空后的草稿一次暂存。它不是已保存记录，不推进进度。服务端确认后原子替换为正式历史，不重复显示。正常等待不显示异常框；求助/恢复操作不清空草稿，仅在操作区显示状态，不伪造用户文字消息。
- 明确 submission=not_committed 时保留失败气泡，不把原文回填输入框。气泡左侧刷新图标重试原请求；输入区用于新草稿，新发送替换旧的本地失败气泡。失败原因在气泡下简短展示，详情按需展开；不再提供「放弃重试并编辑」。
- 网络中断等未知结果自动核对一次服务端记录，不自动重发模型请求。气泡重试先核对，再复用原内容、requestId 和版本；不能改用新草稿。未知期间主按钮为「核对状态」，未确认前不另发新内容；查不到记录不代表原请求已取消。版本已变化且无本次回执时，显示冲突提示，由用户核对当前题后重新发送。
- 确认已保存只清除对应的提交备忘，不再清空输入框；重试、同步和迟到响应都保留后来输入的草稿，即便正文恰好与原消息相同。
- 恢复到已保存的当前任务；通过的回答与下一问同时恢复，不重复生成。若记录处于 awaiting_continue，则提供一次“恢复对话”入口；正常作答不逐题确认。字段与提交顺序统一见 [数据契约](data-contracts.md)。
- 文字草稿、解释模式及原提交备忘分别放在同一份 sessionStorage 记录中，支持同标签页返回/刷新恢复，不写入学习 JSON；关闭标签页后不保证保留。浏览器暂存不可用时就近提示不要刷新，当前页仍可输入；不默认保存原始录音。
- “返回首页”只在无在途请求时可用：已提交内容自动保存，无需再建暂停接口。未提交草稿明确不属于已保存对话；提交失败时可重试，也可确认返回，保留当前标签页的草稿与备忘。
- 有草稿或待确认提交时，应用内返回使用小型确认弹窗：继续练习保留输入，返回首页离开当前页；待确认提交不能宣称已保存，其重试备忘不因返回而清除。无草稿、无待确认提交时直接返回。关闭/刷新浏览器的离开警告仍由浏览器负责。
- 页面阅读文本与草稿使用浏览器原生选词/拖选复制，输入框支持系统粘贴；仅历史对话消息提供主动点击的复制图标，头图、提示和输入框下方不加图标，不自动读取剪贴板或在双击时自动复制。消息旁的收藏仅为未开放占位，不改变收藏或进度。参考表达将可选文字与「填入回答」操作分开，避免选词误改草稿。提交中输入框只读而非禁用，允许复制但不可编辑或重复提交；复制操作不影响进度或记录。
- 首版单人本机使用，当前权威记录保存在 `data/triptalk.sqlite`，不是浏览器缓存；原 JSON 仅留档。用户配置记住上次主动选择的场景；场景进度仍由会话计算。清除浏览器缓存不应删除记录；更换电脑需要迁移数据或后续同步方案。本地服务必须运行，云端 AI 调用需要网络。安全迁移与备份规则见数据契约，不在页面暗中清空或重建记录。
- 已有会话始终使用创建时的配置快照、生成计划、已确认事实和实际问答；新配置只用于新会话，不重新随机或重映射旧问题。损坏/不支持的记录报错保留，不自动清空或跳题。
- 首次问候完成、学习进度、已完成场景、收藏和错题是独立状态，不能仅用“访问次数”判断是否完成课程。

## 6. Jane 问候与情绪规则

### 6.1 选择顺序

**建议默认：**先确定首次 / 续学 / 完成等学习状态，再参考用户主动选择的心情、可用天气、来访频率，最后从符合条件的文案池随机选取。学习状态与下一步按钮必须一致；缺少条件时使用通用台词，不补造天气或情绪。

- 首次自我介绍固定；后续按用户当地日期更换每日基础问候，尽量不与上次重复。
- 每次新进入课程有一句简短课程引导；同一会话内切换 Tab 不重复播放完整欢迎。
- 同一天多次访问可用“又见面啦”等简短变体，不增加打卡压力。
- 建议“连续来访”指连续 3 个本地日期有学习活动；“久未见面”指距上次学习至少 7 天；具体阈值可配置。
- 心情选择可跳过，建议仅当天有效；“没有选择”按未知处理，不能自动解释为不开心。
- 天气由用户选择城市或主动授权位置后获取；未知、未授权、获取失败或缓存过期时不出现实际天气陈述。天气服务待补充。
- 天气与用户心情不同，不把“下雨”自动等同“用户难过”。不需要收集摄像头信息来猜测心情。

### 6.2 表情与动作映射

| 场景 | 表情 / 动作 | 示例台词 |
| --- | --- | --- |
| 首次见面 | 开心、挥手、轻甩马尾 | Hello，我是 Jane！很高兴和你成为朋友，让我们一起学习吧。 |
| 恢复课程 | 微笑、指向进度卡 | 上次停在早餐问询，我帮你留着进度呢。 |
| 连续学习 | 开心、轻点头 | 又见面啦！今天也让一句英语变得更顺口吧。 |
| 久未来访 | 温和、挥手 | 好久不见，按你的节奏来，我们可以先复习一句。 |
| 用户选择有点累 | 安静、柔和微笑 | 今天慢一点也很好，要不要先练一句？ |
| 已知雨天 | 温柔、稍微歪头 | 今天下雨，我们来一场室内的餐厅小旅行？ |
| 幽默片段 | 眨眼、轻笑 | 行李可以超重，今天的单词量不用。 |
| 忧郁氛围 | 轻微垂眼、随后恢复平静 | 今天慢慢来，一句一句也能走得很远。 |
| 轻微生气 | 俏皮嘟嘴、短暂皱眉 | 行李又绕了一圈？我们去问问工作人员。 |
| 回答需要修改 | 专注讲解、指示句子 | 这里补上 is，句子就完整了。 |
| 完成任务 | 开心、轻握拳 | Nice work！你完成了酒店入住练习。 |

情绪服务于场景和陪伴：不因答错、缺席或拒绝练习责备用户；不要求用户安慰 Jane。“有点累只练一句”入口可以去短复习，不能把一句练习记为整课完成。

### 6.3 声音与动效

- 建议欢迎动作 2–3 秒、课程引导 1–2 秒，可跳过；待机只用轻微呼吸与眨眼，支持静态模式。
- 不强制有声自动播放；首次由用户主动开启声音，随后遵循浏览器策略与用户设置。
- 优先级建议：当前任务反馈 > 课程开始 / 完成 > 问候 > 待机；切换时停止过时语音，避免同时播两句。
- P1.6 句子点播显示待机/播放/停止状态，与录音互斥；交互统一见第 4.8 节，完整声音角色设计仍后置。
- 支持系统减少动态效果偏好；动画失败时显示静态 Jane，学习操作继续可用。
- 音色、口音、语速、说话口型同步和动画技术方案：**待补充**。

## 7. 错题本与复习

以下为**建议默认**。

- 每条错题保留题目、本轮意图、用户原回答、推荐表达、简短解释、来源场景、最近出错时间和复习状态。
- 初版按“来源训练会话＋计划问题 ID＋错误类型”去重，跨随机计划的语义合并后置；重复错误增加次数，不反复新增相同卡片。
- 状态为“待复习 → 待巩固 → 已巩固”。第一次复习通过进入待巩固；不同日期再次通过才进入已巩固；之后再错则回到待复习，重置有效通过次数。同日重复通过不刷巩固等级。
- 复习优先安排到期项；建议新错题次日到期、第一次通过后 3 天、再次通过后 7 天维护复习。已巩固项到期仍可进入队列；同日重复通过不推迟到期；“之后再错”在课程练习和复习中均适用，次日重新到期。此为首版产品建议，不作为保证记忆效果的承诺。
- 列表支持场景筛选、查看解释和“开始复习”；练习时先给问题，再展示答案与 Jane 反馈。
- 答对后只更新对应表达；不批量清空整本错题。跳过不标为通过。
- “待处理”角标显示待复习及待巩固的有效条目数；“今日待复习”只统计今天到期项（含已巩固维护项）。两个数字明确命名，变化与卡片状态一致。
- 同一个意思的正确变体不记错；仅“可以更自然”的建议放入可选收藏，不计入错误次数。
- 空状态：“还没有待复习的错题，去练一个旅行场景吧。” 不为了填满页面伪造数据。

## 8. 随身表达本与设置

**建议默认：**表达本由用户主动收藏；收藏显示已收藏状态并去重，可按场景查看、取消收藏；取消收藏不删除错题或课程记录。表达卡保留英文、中文、例句和来源。

设置集中放置：中文辅助、声音开关、语速、减少动效、天气城市、学习记录。未接入的功能不伪装可用。清除记录需要明确二次确认，说明会删除本机的哪些数据。

Jane 识别点、角色设定图、动画模板及输出限制统一维护在 [设计索引](../design/README.md)。该设定图不是已完成动画；P1 只需单人静态素材。

## 10. 响应式与异常状态

- 桌面：固定位置的顶部导航、Jane 与气泡横幅，下方切换首页/对话/复习内容；首页场景卡可多列。手机将 Jane 收为紧凑半身或头像与短引导，始终保留人物，不挤占主要答题区。
- 所有按钮有清楚文字，能键盘操作；反馈不只依赖颜色，动效不遮挡操作。
- 网络失败：保留已输入文字，允许重试；不要重复提交、重复计错或重复生成完成记录。
- 评估超时：显示“暂时无法判断”，允许重试或暂停，不强行判错或判对。
- 天气失败：换用普通问候；语音失败：提供文字；角色图片失败：保留 Jane 名称与文字引导。
- 加载、空列表、禁用按钮、保存失败和权限拒绝均需有明确状态。
- 建议在项目本地文件保存用户主动选择的当日心情，不默认保存原始录音。首版不做账号；跨设备与数据保留政策待补充。发送云端模型的范围与本地归档不同，见 [OpenAI 接入说明](openai-setup.md)。
